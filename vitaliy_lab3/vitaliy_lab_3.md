## Задание №2. BPMN-диаграмма AS-IS

**Описание схемы (текстовое):**
1. Пациент поступает в приемный покой → регистратор заполняет бумажный журнал учета и открывает карту стационарного больного.
2. Врач приемного отделения осматривает пациента, делает запись в карте → передает в профильное отделение.
3. Старшая медсестра вручную проверяет бумажный журнал занятости палат → назначает койку → санитары готовят палату.
4. Лечащий врач заполняет лист назначений → медсестра фиксирует выполнение в бумажном журнале процедур.
5. При необходимости анализов врач заполняет бланк-заказ → биоматериал передается курьеру в лабораторию → лаборатория вручную регистрирует пробу → проводит исследование → печатает протокол → курьер доставляет бумажный результат → врач вклеивает его в карту.
6. Ежедневные обходы, фиксация температуры/состояния в бумажном температурном листе.
7. Принятие решения о выписке → ручное написание эпикриза → передача копии в поликлинику почтой/факсом → закрытие карты → передача в архив.

## Задание №3. Выявление проблем (AS-IS)

| Возможная проблема | Причина | Последствие |
|---|---|---|
| Ручное дублирование данных в нескольких журналах и картах | Отсутствие единой цифровой среды; исторически сложившаяся бумажная отчетность | Высокий риск ошибок при переписывании, потеря данных, дублирование функций персонала, увеличение времени оформления |
| Задержки получения лабораторных результатов (1–3 дня) | Физическая транспортировка бланков и биоматериала, отсутствие интеграции с внешними лабораториями | Затягивание постановки диагноза, риск ухудшения состояния пациента, неэффективное использование койко-дней |
| Отсутствие реального учета свободных коек | Учет ведется в бумажных журналах старшей медсестры, обновление данных происходит раз в смену | Накладки при госпитализации, простои коек, очереди в приемном покое, невозможность быстрого перевода между отделениями |
| Потеря/порча бумажных документов и карт | Физическое хранение, большой поток перемещений между кабинетами, архивация | Юридические и медицинские риски, невозможность восстановления истории болезни, штрафы при проверках |
